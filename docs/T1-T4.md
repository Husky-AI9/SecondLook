# Keyboard tests T1–T4: what is automated and what needs the iPhone

From `implementation.md` §3. The **build** half runs on GitHub Actions. The **phone** half
needs someone holding the iPhone; the keyboard has a test bench so that takes about ten
minutes, most of it waiting for T2's five-minute clock.

## Build half (GitHub Actions)

Actions → **iOS unsigned .ipa** → Run workflow (leave "keyboard" on). The job:

1. installs dependencies and runs `expo prebuild` with the keyboard target,
2. compiles the app, the Firebase AI Logic module and the keyboard extension,
3. checks that the `.appex` is inside the app and prints both bundle ids,
4. uploads `SecondLook-unsigned.ipa`.

A green run is the build half of **T1**, and means the T2 and T4 code compiles.

## Phone half (you, about ten minutes)

Before you start: iPhone 15 Pro or newer, iOS 26, **Apple Intelligence turned on**, phone
**plugged in to power**.

1. Download the `.ipa` artifact and install it with Sideloadly (free Apple ID).
2. Settings → General → VPN & Device Management → trust your Apple ID.
3. Settings → General → Keyboard → Keyboards → Add New Keyboard → **SecondLook**.
   Leave **Allow Full Access off** for the first pass.
4. Open the SecondLook app → Settings (top right). Find **Keyboard test bench**.
   - Note the **App id** line. *T1 passes if it is `com.secondlook.app`* (or the id you
     registered in Firebase). If Sideloadly changed it, that is the id to register.
   - Tap **Write T4 value**.
5. Tap the test box on that screen, hold the globe key, choose **SecondLook**, tap **Tests**.
   *T1 passes if the panel appears here and in Messages.*
6. **T4**: tap `T4`. Pass = `T4 PASS: read "app wrote …"`.
7. **T2**: tap `T2` eight times, spread over five minutes (about one tap every 40 seconds).
   Each tap should type a sentence into the box. Pass = the line `T2 PASS` after the eighth.
8. **T3**: tap `T3`. In the first build it says Firebase is not linked into the keyboard;
   that is expected until T1/T2/T4 are known.
9. Tap **Paste log**, then copy the text out of the box and send it to Claude.
10. Turn **Allow Full Access on** (Keyboards → SecondLook) and repeat steps 6, 7 and 9.
    The log header records Full Access on or off, power and free memory for each pass.
11. Optional, for the battery note in the plan: unplug and tap `T2` a few more times.

If the keyboard disappears mid-test, iOS killed it for memory. Note which tap; that is a T2
fail.

## Reading the result (from the plan)

| Result | What gets built |
|---|---|
| All pass | Plan A in full |
| T3 fails, rest pass | Plan A-lite: the keyboard calls Apple's model directly (what this build does) |
| T4 fails, rest pass | Plan A with clipboard import: app → Keyboard tab → "Copy pack code" |
| T1 or T2 fails | Plan B: the main app without the keyboard |
